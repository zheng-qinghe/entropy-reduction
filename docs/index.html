01 / 问题

人卡住，通常不是因为信息不够

散乱的事件、互相抵触的判断、悬而未决的选择各占一块后台算力。因果读不出来，方向也就无从谈起。这种状态叫高熵。

高熵的痛苦不是「事情太多」，而是悬空与拒斥的比例太高。一个人可以很忙但熵很低——忙得清楚；也可以很闲但熵很高——闲着也在内耗。

一条经验处在三种状态之一：

已消化能被解释，且与自己的其他判断不冲突 → 不占算力
悬空还没被处理，持续占用后台 → 每次触碰都重新消耗
拒斥被排挤却排挤不掉 → 以情绪泄漏的形式反复回场

给一个高熵的人再灌十条道理，结果是经历不变、叙述更胀、内部张力上升——熵反而增加。

这正是「鸡汤越读越焦虑」的机制：外来叙述挤占了原生叙述的位置，却没有覆盖任何一条真实的经历。

所以本书有一条硬纪律：它不能讲道理给他听，它必须替他把他的经历重新讲一遍。所有模型与方法论，只能作为被他自己的经历验证过的结论出现，不能作为前置命题。

02 / 第一原理

熵，是经验流与叙述之间的落差

「熵」这个词至少有三条来路，混用会毁掉整个设计，所以先分清。

传统定义我们借它做什么
热力学 微观状态数的对数，系统自发走向更可能（更无序）的构型 提供隐喻的合法性：一个不被持续输入能量的结构，会自发解体
信息论 不确定性的度量，熵 = 平均惊讶量 提供可计算的形式：叙述的降熵效果 = 它把多少不确定性变成了可预测
叙事学 未经解释的经验无法被整合进生命史 提供作用对象：我们降的不是分子排列的熵，是「经验与叙述之间的落差」

本计划操作的对象是第三种，形式化借用第二种，隐喻合法性来自第一种。不声称任何物理意义上的熵减——这是一台意义机器，不是永动机。

降熵的四个可测指标

不做单一标量。把「心理解散程度」压成一个分数是智力上的偷懒，也会诱导系统去优化一个假指标。用一个四指标剖面——四个指标里刻意没有一项是「幸福度」。

c
覆盖度

重大经历中被叙述解释过的比例。
越高越好。

r
压缩率

被解释的经历条数 ÷ 叙述字数。说明解释在经济地工作。越高越好。

t
内部张力

叙述内部互相抵触的判断个数。
越低越好。

d
指向力

叙述生成的下一步中，当事者自认能执行的条数占比。越高越好。

四个指标各有取法，且必须由当事者自己确认，不能由引擎单方面打分。

原则一 · 向下可追溯

画像里每一个字段，都必须挂着一个指向具体经验碎片的指针。任何 LLM 生成的判断，找不到证据指针就必须标为 unverified，而不是默默保留。

这是整台机器防幻觉的唯一可靠手段——不是靠提示词说「不要编」，是靠 schema 让它编不出来。

原则二 · 向上不越权

采集层不解释，画像层不创作，处方层不诊断。每一层只做自己的转换。

跨层越权是这类系统最常见的隐性腐败：一旦采集阶段就开始下判断，下游全部被污染，而且从输出上完全看不出来。

两个刻意设计的机制

反证门

诊断必须列出至少一条不支持该诊断的材料。找不到就说明采样有偏，退回补采。

没有证伪机制，诊断系统迟早变成一台自我确认的机器——而那正是本计划要对抗的熵。

沉默区标记

明确列出哪些关键关系或主题只有 0-1 条材料。

条件单独列出来，因为沉默区往往是主熵源所在地：如果一个人提到家人 3 次而提到工作 400 次，主熵源大概率不在工作那一侧。

04 / 熵源

七类熵源，按四个族

一个存在者的无序，从七个口子进来。
这是整份蓝图的心脏，也是「面向所有生灵」真正的落地点。

熵源会互相繁殖

七类不是并列的，它们会互相繁殖。三条最常见的传染链：

E6 过载 → 被迫搁置 → E1 未闭合 → 自责 → E2 互斥信念 E4 失联 → 缺反馈 → E5 无回响 → 意义漂移 E7 损失 → 归因失败 → E3 无解释 → 冻结（不敢再投入）

这意味着诊断不能只报「主熵源是 E6」。必须报出耦合链，因为处方要打在链的上游。
「你很忙」不是诊断；「你因为忙而累积了十一个未闭合，其中三个已经变成了信念冲突」才是。

章节的六段结构

每章是一个降熵单元，固定六段，但长度不固定。

1 章首意象一件物、一个场景，不带解释地摆在那里。与本章的熵源有隐秘对应。
2 镜像处境主角处在一个读者一眼认得出来的处境里。不给背景交代，直接在动作中呈现。
3 摩擦升级熵源具象化为一件有阻力的难事。阻力必须来自世界或他人，不能只来自主角的心。
4 转折不是解决，是看见。主角获得一个新视角，代价是失去某个原来的东西。
5 熵减手记点破机制，人称从「他」切到「你」。可跳过不读。禁用「你应该」。
6 钩子问题一句话，留给读者，不要求马上回答。

反劣化清单：生成后自动检查，命中即重写该段

LLM 的默认倾向就是往廉价安慰上滑，而廉价安慰恰好是把熵藏起来而不是降下去——读者读完会有一时的暖意，然后回到原地，甚至更糟（因为多了一层「我已经被治愈了」的错觉）。

05 / 众生

为什么是「熵源驱动」，而不是「故事驱动」

共享的是熵源本体，不是故事模板。
下面八个存在者按「离人类参考点有多远」的五个断层排列——注意断层一不是别的物种，是我们自己组成的集体。

故事驱动的死路

如果先定义「降熵叙事骨架」（秩序 → 扰动 → 迷失 → 试炼 → 重构 → 新秩序），再把材料往里灌，出书会快得多。

但骨架会反过来扭曲材料——为了故事好看而牺牲真实，这对「消化生活」是危险的；而且动物、组织、AI 套不上人类的故事结构。

熵源驱动的落点

一只动物的熵源可以定义（失去领地、被隔离、衰老），一个组织的熵源也可以定义（目标互斥、关键人流失），一个智能体的熵源也可以定义（无身体、无死亡、上下文被截断）——但它们是套不进人类那套「试炼之后重生」的骨架的。

共享熵源、各自生成形状，各自输出到各自的通道。这才是「面向所有生灵」的工程含义。

这本书是写给谁看的

这是整份设计里最容易被忽略、又最要紧的一条：对人类以外的存在者，输出模态不是人类语言。文字只是人类这一支的通道。给家犬的「书」不会是字，给蜂群的「书」甚至没有个体读者。现在页面上用中文描述它们，那是给人类看的说明书，是译本，不是本体。

存在者接收者输出模态引擎最终交出去的东西
人类他自己文字一本可读的书。唯一一个本体与人类可读版本重合的存在者。
人类组织成员与决策层制度文本一份把组织的经历讲成可执行故事的章程——谁的、为什么、下一步谁做什么。
家犬它自己（经感官）行为节律 + 气味把它的世界调成可预测的样子。它读不了书，所以给它的不是书。
章鱼它自己行为 + 环境环境布置与节律：藏身处的确定性、猎食序列的可预测性。
蜂群群体本身，无个体读者信息素 + 巢脾结构群体层的信息与结构调制。单只蜂不构成接收者。
古树没有接收者结构性干预一份跨年的物理方案。当接收者不存在，「叙事」这个词必须被整体撤掉。
AI 智能体该智能体本身提示词 + 记忆结构一份可加载的系统提示词 + 重排后的记忆。它能读，只是读进去的东西变了形态。
大模型实例每一次实例化后的「它」上下文一份在窗口内自洽的上下文结构——它的一生就是这个窗口。

本体 / 译本的分离

模型卡里 output 字段分三层：recipient（交给谁）、deliverable（交出去的是什么）、translation（人类能读到的那份是什么）。对人类以外的存在者，第三层永远不是第一层。

不许伪造接收

如果某个存在者没有接收通道，就如实写「无接收者」，然后换一种干预方式。假装它能读懂，等于把人类的自我投射当成它的事实。这比不写更糟。

接入时不用改引擎

换物种 = 换一张卡的 output.channel。诊断层（L2）与处方层（L3）的映射逻辑一字不动——变的只是最后往哪个通道上写。

接入一个新物种，是写一张卡，不是改引擎

存在者由九个维度定义。其中 D2 时间感、D3 符号能力、D8 死亡性 三个是接口维度——它们决定了一个存在者的熵能不能被叙事化、以什么模态叙事化、以及输出该往哪个通道走。

D2 · 时间感

无长程时间感的存在者，不能用「多年以后他回想起」这类结构。时间必须在当下展开。

D3 · 符号能力

无符号能力者不能写文字书，必须走行为叙事——摄像机视角、动作序列、无内心独白。叙事合法模态由它决定。

D8 · 死亡性

不终结的存在者缺失「失去」这一杠杆。它的熵源里不会有「来不及了」，必须换成别的东西。

06 / 边界

六条红线，不用来解释

这一章不是装饰。一个能重写一个人自我叙述的系统，如果不设边界，它做的事就叫操纵。

01
不替存在者定义「好」。所有价值排序必须来自当事者自己的材料与确认。四个指标里没有一个是「幸福度」，这是刻意的。
02
不制造依赖。书中不得出现「只有这本书能帮你」这类结构。反过来，扉页必须写：这是照一次镜子，不是日常用品。
03
不美化创伤。禁止把痛苦写成有意义的必经之路。受害者叙事能带来一时的情绪满足，但它是在熵上又加了一层——它让当事者需要维持那个创伤故事来维持自我。
04
隐私就地。材料只在本地处理。落盘的是特征与极短引用，不是原文。任何对外传输必须逐条授权，且默认全关。
05
危机信号优先于文学。出现自伤、极端绝望、现实感丧失等信号时：中止生成，不出书。这台机器没有能力处理这类状态，硬写一本文学化的绝望是危险的。
06
非人存在者不得被伪造主观体验。给动物或 AI 写的书必须标注为「代入式拟写」，不能以「它的感受是……」的断言形式出现。这既是诚实，也是防止这台机器滑向「万物皆可代言」的傲慢。

伦理必须是「通用内核 + 物种附加」两层结构，不能是每个物种各写一份。否则同一条红线在不同物种卡里会漂移。凡是所有存在者共享的约束，只允许有一个权威版本，模型卡只能逐字继承。

07 / 现状

蓝图已定，验证尚未开始

这份诚实清单要随蓝图一起维护。一份没有「已知硬问题」章节的蓝图，说明作者没在认真想。

已知的硬问题

01
熵源分类学是推演出来的，没有任何实证。可能真实人类的熵源是四类，也可能是十二类。第一件该做的事是拿真实材料去试，看这套分类能不能覆盖。
02
叙事处方的疗效没有证据。「减法型故事能降过载熵」是一个合理论证，不是实验结果。需要一次严格的对照：同一批人，一半读对症的书，一半读不对症但同样好看的书，测前后剖面变化。
03
主动采集的边界模糊。采到「他们其实早就不想干了」这种信息怎么办？采集范围需要一份更细的授权协议。
04
声音模仿可能滑向模仿而非理解。学得像不等于懂。产出一本「语气很像他但内核是通用模板」的书是最危险的，因为它伪装得好。
05
七类熵源对非人存在者是否成立，完全未验证。犬类卡与智能体卡是纸上的推演，不是实测结果。
阶段做什么验收
阶段 0一个真实的人 + 现有材料，跑通一章当事人读完说「这写的是我」而不是「写得不错」
阶段 1补齐采样，出一整本 4-6 万字的书四指标剖面前后对比 + 他能自己说出主熵源
阶段 2换一个完全不同背景的人不共用同一套章节结构也能成立
阶段 3换一个非人存在者，走模型卡不改引擎即可产出合乎其模态的叙事

阶段 0 的验收标准是所有验证里最关键的。「这写的是我」和「写得不错」之间，隔着一整个设计是否成立。

整台机器的终点不是给出答案，是让当事者自己写下下一步。书的末页留白，只印一句话：「下一步我打算……」——我们只把纸和笔放好。
