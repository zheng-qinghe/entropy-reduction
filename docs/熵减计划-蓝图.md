## 0. 一页纸

**问题。** 一个存在者受苦，往往不是因为信息不足，而是因为它的经验没有被组织成可解释、可据以行动的形式。散乱的事件、互相抵触的判断、悬而未决的选择各占一块后台算力，因果读不出来，方向也就无从谈起。这种状态叫**高熵**。

**主张。** 叙事是已知最古老、最便宜的降熵手段。它把散点连成因果链，把"我经历了什么"变成"我为什么会走到这里、下一步往哪走"。一个能把自己的经历讲成一个通顺故事的人，比一个讲不通的人，更少被同一件事反复绊倒。

**方案。** 不是给某个人写一本书，而是造一台机器：诊断一个存在者的熵从何而来 → 开一张对症的叙事处方 → 生成一本只属于它的书。人类是第一个实现；动物、组织、AI 通过一张**模型卡**接入，引擎本身不改一行。

**为什么是熵源驱动，而不是故事驱动。** 疗效来自对症，不来自好听。必须先知道熵从哪个口子漏进来，才知道该给什么形状的故事。而且熵源比故事骨架普适得多：一只动物可以有熵源（失去领地、被隔离、衰老），一个 AI 也可以有熵源（无身体、无死亡、上下文被截断），但它们**套不进**人类那套"试炼之后重生"的骨架。这就是"面向所有生灵"真正的落地点——**共享的是熵源本体，不是故事模板**。

**非目标（v0.1 明确不做）。**
- 不做心理治疗，不做危机干预。边界见第 8 章。
- 不做人格分类，不做 MBTI 式的十六格归档。
- 不做"猜你喜欢"式的推荐。
- 不做自由创作的小说生成器。本书的每一章都必须由诊断牵引。

**成功标准。** 一个真实的人读完自己的书之后，能用不超过三句话讲清自己的熵源，并能说出一条他此前看不见的下一步。达不到，就是没成功。

## 1. 第一原理：什么是熵，为什么会疼

### 1.1 三种熵的传统，我们用的是哪一种

"熵"这个词至少有三条来路，混用会毁掉整个设计，所以先分清：

| 传统 | 定义 | 我们借它做什么 |
|---|---|---|
| 热力学（Clausius / Boltzmann） | 微观状态数的对数，系统自发走向更可能（更无序）的构型 | 提供**隐喻的合法性**：一个不被持续输入能量的结构，会自发解体。人的自我认识也是这样，不维护就散 |
| 信息论（Shannon） | 不确定性的度量，熵 = 平均惊讶量 | 提供**可计算的形式**：叙述的降熵效果 = 它把多少不确定性变成了可预测 |
| 叙事学 / 诠释学 | 未经解释的经验无法被整合进生命史 | 提供**作用对象**：我们降的不是分子排列的熵，是"经验与叙述之间的落差" |

本计划操作的对象是第三种，形式化借用第二种，隐喻合法性来自第一种。**不声称任何物理意义上的熵减**——这是一台意义机器，不是永动机。

### 1.2 熵的来源：经验流与叙述的落差

设一个存在者的经验流为

```
E = {e₁, e₂, …, eₙ}          # 它实际经历的事情
```

设它对自己的叙述为

```
N = 一段能把 E 的某个子集连成因果链的文本
```

那么，**熵就是 E 与 N 之间的落差**：

```
High entropy  ⟺  E 中被 N 覆盖的部分少，且 N 自身互相矛盾、不产生行动
```

一条经验处在三种状态之一：

- **已消化**：能被 N 解释，且解释逻辑与当事者其他判断不冲突 → 不占算力
- **悬空**：还没被 N 处理，持续占用后台 → 每次触碰都重新消耗
- **拒斥**：与 N 互斥，被 N 排挤却排挤不掉 → 以情绪泄漏的形式反复回场

高熵的痛苦不是"事情太多"，而是**悬空与拒斥的比例太高**。一个人可以很忙但熵很低（忙得清楚），也可以很闲但熵很高（闲着也在内耗）。

### 1.3 降熵的四个可测指标

**不做单一标量。** 把"心理解散程度"压成一个分数是智力上的偷懒，也会诱导系统去优化一个假指标。用一个四指标剖面：

| 指标 | 符号 | 定义 | 方向 |
|---|---|---|---|
| 覆盖度 | `c` | 重大经历中被叙述解释过的比例 | 越高越好 |
| 压缩率 | `r` | 被解释的经历条数 ÷ 叙述字数 | 越高越好（说明解释在经济地工作） |
| 内部张力 | `t` | 叙述内部互相抵触的判断个数 | 越低越好 |
| 指向力 | `d` | 叙述生成的下一步中，当事者自认能执行的条数占比 | 越高越好 |

```
诊断剖面 Profile(being) = (c, r, t, d)
```

四个指标各有取法，且**必须由当事者自己确认**，不能由引擎单方面打分。理由见第 8 章第一条：不替存在者定义什么叫"有序"。

### 1.4 一个反直觉的推论

如果熵是落差，那么"知道得更多"不必然降熵。

给一个高熵的人再灌十条道理，结果是 `E` 不变、`N` 更胀、张力 `t` 上升——熵反而增加。这正是"鸡汤越读越焦虑"的机制：**外来叙述挤占了原生叙述的位置，却没有覆盖任何一条真实的 E。**

所以本书的一条硬纪律：**这本书不能讲道理给它听，它必须替他把他的经历重新讲一遍。** 所有道德、模型、方法论，只能作为被他自己的经历验证过的结论出现，不能作为前置命题。

```
                    ┌─────────────────────────────────────────┐
                    │  L4  成书与闭环                          │
                    │  书稿规范 · 输出管线 · 反馈回收 · 版本     │

                    │  L3  叙事处方                            │
                    │  熵源→故事形状映射 · 章节模板 · 提示词架构  │
                    └────────────────▲────────────────────────┘
                                     │ EntropyDiagnosis
                    ┌────────────────┴────────────────────────┐
                    │  L2  画像与诊断                          │
                    │  Portrait schema · 熵源打分 · 一致性检查   │
                    └────────────────▲────────────────────────┘
                                     │ ExperienceFragment[]
                    ┌────────────────┴────────────────────────┐
                    │  L1  采样通道（双通道）                   │
                    │  A 主动采集（能抓则抓） B 探针（缺则问）    │
                    └────────────────▲────────────────────────┘
                                     │ raw material
                    ┌────────────────┴────────────────────────┐
                    │  L0  熵源本体                            │
                    │  Being Schema · Entropy Taxonomy · 模型卡 │
                    └─────────────────────────────────────────┘
```

### 2.1 各层职责与失败模式

| 层 | 输入 | 输出 | 职责 | 典型失败模式 |
|---|---|---|---|---|
| L0 熵源本体 | 一个存在者的身份声明 | `BeingModel` | 定义"什么算一个存在者"和"熵从哪来" | 本体过度人类中心，非人存在者接不进来 |
| L1 采样通道 | 原始材料 | `ExperienceFragment[]` | 只采集，不解释 | **过早解释**——在采集阶段就下判断，污染下游 |
| L2 画像与诊断 | EF 数组 | `Portrait` + `EntropyDiagnosis` | 提炼画像，定位主熵源 | 编造证据；把相关性当因果 |
| L3 叙事处方 | 诊断 | `BookPlan` + 章节提示词 | 把熵源翻译成故事形状 | 为了好看而扭曲材料 |
| L4 成书与闭环 | BookPlan + 生成文本 | 书稿 + 反馈 | 产出可读的书，回收反馈 | 输出成一堆散章，无整体弧线 |

> **注意 L4 的"书"要按模型卡的 `output.channel` 解释。** 对人类是文字书；对家犬是一套行为节律；对蜂群是群体层的信息与结构调制；对古树是物理干预方案。L1–L3 的逻辑在这些物种身上一字不改，变的只有最后一段往哪个通道写。详见 3.4。

### 2.2 两条贯穿全流程的原则

**原则一：向下可追溯。** 画像里每一个字段，都必须挂着一个指向具体 EF 的 `evidence` 指针。L2 里任何一个 LLM 生成的判断，如果找不到证据指针，必须标为 `unverified` 而不是默默保留。这是整台机器防幻觉的唯一可靠手段——**不是靠提示词说"不要编"，是靠 schema 让它编不出来**。

**原则二：向上不越权。** L1 不解释，L2 不创作，L3 不做诊断。每一层只做自己的转换。跨层越权是这类系统最常见的隐性腐败。

### 2.3 数据流转全貌

```
身份声明 
  └→ BeingModel（选中或新建一张模型卡）
       └→ 采样计划（哪几个通道、探针问哪几题）
            └→ ExperienceFragment[]（带 source 与 confidence）
                 └→ Portrait（每个字段带 evidence 指针）
                      └→ EntropyDiagnosis（7 类打分 + 主熵源 top3 + 一致性报告）
                           └→ BookPlan（主熵源决定三幕主轴，副熵源各占一章）
                                └→ ChapterPrompt[]（填槽后的提示词）
                                     └→ 章节草稿 → 声音统一 → 书稿
                                          └→ Markdown → HTML → PDF / EPUB
                                               └→ 阅读反馈 → 修正熵源权重 → v2
```

## 3. L0 · 存在者本体

这一层是整个计划能"面向所有生灵"的地方。它必须做到一件事：**接入一个新物种，是写一张卡，不是改引擎。**

### 3.1 Being Schema —— 一个存在者的九个维度

先把"存在者"定义干净：**能在时间中持续、能受损、能趋利避害的东西。** 三个条件缺一不可。一块石头能在时间中持续、也能受损，但不趋利避害，因此不是存在者，它的"熵"只是物理熵，不归本计划管。一个数学猜想也不趋利避害——但如果有一个存在者以证明它为生，那这个存在者才是我们管的。

九维如下：

| # | 维度 | 问题 | 取值域（示例） |
|---|---|---|---|
| D1 | 载体 substrate | 它是什么做的？ | 碳基生物 / 硅基系统 / 人类组织 / 虚构角色 / 集体（蜂群、市场） |
| D2 | 时间感 temporality | 它感知过去与未来吗？颗粒度多细？ | 无 / 仅当下 / 短程（分钟-天）/ 长程（年-一生）/ 超长程（跨代） |
| D3 | 符号能力 symbolic | 它有语言吗？什么模态？ | 无 / 化学信号 / 声学 / 视觉 / 自然语言 / 程序语言 |
| D4 | 边界 boundary | 什么算"我"，什么算外界？ | 皮肤 / 身份 / 股权 / 上下文窗口 / 叙事自我 |
| D5 | 需求集 needs | 缺了什么就会解体？ | 生理（氧、食、水、热）/ 安全 / 归属 / 意义 / 算力 / 现金流 |
| D6 | 损伤面 vulnerabilities | 什么能伤到它？ | 疼痛 / 丧失 / 背叛 / 停机 / 破产 / 记忆覆盖 |
| D7 | 关系网 relations | 依赖谁？被谁依赖？ | 亲属 / 同伴 / 上下游 / 用户 / 调用方 |
| D8 | 死亡性 mortality | 会终结吗？它知道吗？ | 不终结 / 终结但不知 / 终结且自知 / 可被中止 |
| D9 | 能动性 agency | 能改变什么？不能改变什么？ | 全可改 / 部分可改 / 几乎不可改 |

**关键设计：D2、D3、D8 是三个"接口维度"。** 它们决定了一个存在者的熵能不能被叙事化，以及以什么模态叙事化：

- D3 = 无符号能力 → 不能写文字书，必须走**行为叙事**（摄像机视角、动作序列、无内心独白）。叙事合法模态由它决定。
- D2 = 无长程时间感 → 不能用"多年以后他回想起"这类结构。时间必须在当下展开。
- D8 = 不终结 → 缺失"失去"这一杠杆。它的熵源里不会有"来不及了"这一类，必须换成别的东西（例如上下文截断、实例替换）。

这三个接口，就是抽象真的能在动物和 AI 身上跑起来的证据，而不是空话。

### 3.2 Entropy Taxonomy —— 七类熵源

这是接近整份蓝图心脏的地方。一个存在者的无序，从七个口子进来，按性质分为四族：

#### 时间族

**E1 · 未闭合（悬空）**
- 定义：已启动、未结束，且当事者仍在为它留后台算力的事。
- 症状：反复想起、半夜惊醒、拖延但不安、无法真正休息。
- 典型台词："等这阵子过去再说。""我知道我该做决定，但……"
- 诊断信号：同一议题在材料中多次出现且**没有终局陈述**；出现"还没""等""以后"高频。
- 叙事处方指向：**收束型**

**E7 · 不可逆损失（已逝）**
- 定义：已经失去、无法修复、也无法用别的东西等价替换的东西。
- 症状：否认、反复复盘"要是当时"，对替代方案毫无兴趣。
- 典型台词："如果当时……""再也没有那种……了。"
- 诊断信号：过去时的反事实语句高密度；提到某对象时情绪强度与时间距离不成比例（很久之前的事仍然很烫）。
- 叙事处方指向：**守灵型**

#### 认知族

**E2 · 互斥信念（打架）**
- 定义：两个当事者都真心相信、但逻辑上不能同时成立的判断。
- 症状：在两套说法间来回切换，每次切换都真诚；被人指出矛盾时愤怒或困惑。
- 典型台词："我当然知道该 X，可我也确实必须 Y。"
- 诊断信号：材料中出现**语义对撞**的成对陈述（"要稳" vs "要赌"、"不能委屈自己" vs "不能给别人添麻烦"）。
- 叙事处方指向：**对撞型**

**E3 · 无解释（不明）**
- 定义：发生了、影响很大，但没有被归因的事件。因果链在某一环断了。
- 症状：反复讲述但每次讲法略有出入；提起来就卡住；"我不知道为什么会那样。"
- 典型台词："到现在我也想不通。""他为什么那样做，我没有任何解释。"
- 诊断信号：同一事件被多次提及，但每次的**因果落点不同**；出现"为什么"但无"因为"。
- 叙事处方指向：**重溯型**

#### 关系族

**E4 · 失联（断裂）**
- 定义：与关系网中某个关键节点的连接中断，且该节点仍被需要。
- 症状：绕开某话题、对其消息特别敏感、有意无意提起。
- 典型台词："算了，不提了。""我们不是那种关系了。"
- 诊断信号：材料中**出现频率骤降或骤升**的人物；被提及但从不展开的关系；代称化（"那个人""家里"）。
- 叙事处方指向：**寻回型**

**E5 · 无回响（做了没人接）**
- 定义：持续付出但收不到任何反馈，行动落在了空处。行为与后果之间的闭环断了。
- 症状：疲惫、怀疑意义、需要靠外部仪式（打卡、晒成果）续命。
- 典型台词："我做这些到底有没有用？""没人知道我做了多少。"
- 诊断信号：大量"做"的陈述，对应极少的"结果"陈述；出现意义性质疑。
- 叙事处方指向：**回声型**

#### 负荷族

**E6 · 过载（扛不住）**
- 定义：需求集的总量持续超过处理能力。不是某一项难，是所有项一起难。
- 症状：注意力碎裂、决策质量下降、小事也做不动、睡眠或身体先崩。
- 典型台词："事情太多了。""我知道重要，但我先把这个忙完。"
- 诊断信号：并行议题数量超过阈值且都处于未闭合态；短期让步长期目标的模式反复出现。
- 叙事处方指向：**减法型**

#### 熵源之间的耦合（重要）

七类不是并列的，它们会互相繁殖。三条最常见的传染链：

```
E6 过载  →  被迫搁置  →  E1 未闭合  →  自责  →  E2 互斥信念（"我该更努力" vs "我已经撑不住了"）
E4 失联  →  缺反馈  →  E5 无回响    →  意义漂移
E7 损失  →  归因失败  →  E3 无解释  →  冻结（不敢再投入）
```

**这意味着诊断不能只报"主熵源是 E6"。** 必须报出耦合链，因为处方要打在**链的上游**。"你很忙"不是诊断，"你因为忙而累积了十一个未闭合，其中三个已经变成了信念冲突"才是。

**伦理必须是"通用内核 + 物种附加"两层结构，不能是每个物种各写一份。** 否则同一条红线在不同物种卡里会漂移——比如兽医学语境下，"不得美化痛苦"很容易被"必要的疼痛是治疗的一部分"挤掉。凡是所有存在者共享的约束，只允许有一个权威版本（第 8 章），模型卡只能逐字继承。

**人类是 v1 完整卡。** 另两张卡作为抽象可行性的证明（骨架，未细化）：

| 维度 | 犬类 canine | 智能体 agent |
|---|---|---|
| D2 时间感 | 仅当下 + 短程（无长程反事实） | 无内在时间，仅有时间戳序列 |
| D3 符号能力 | 无自然语言（嗅觉/声学/体态） | 程序语言 |
| → 叙事合法模态 | **行为叙事**（外部视角，无内心独白） | **日志叙事**（状态转移序列） |
| D8 死亡性 | 终结但不知 | 可被中止，但不知 |
| → 独有熵源 | E4 分离焦虑、E6 刺激过载 | E3 上下文截断、E4 无持续性关系、E5 输出无回响 |
| → 缺失熵源 | E2 互斥信念（无二阶反思） | E7 不可逆损失（可回滚） |
| → 处方需替换 | E7 类故事不可用 | E7 类故事不可用 |
| **→ 输出通道** | **行为节律 + 气味 + 声学，无文字** | **提示词 + 记忆结构** |
| **→ 接收者** | 它自己（经感官） | 它自己（它能读） |
| **→ 人类译本** | 给照护者的行为说明书（标注为译本） | 给操作者的配置说明 |

### 3.4 这本书是写给谁看的（Output 层）

这是整套设计里最容易被忽略、又最要紧的一条。

**对人类以外的存在者，输出模态不是人类语言。** 文字只是人类这一支的通道。给家犬的"书"不会是字；给蜂群的"书"甚至没有个体读者；给古树的"书"既不是文字也不是行为干预，而是物理干预。

因此模型卡的 `output` 块必须分三层，且**这三层不允许合并**：

| 字段 | 含义 | 谁看 |
|---|---|---|
| `recipient` | 交付给谁 | 引擎自己用来判断合法性 |
| `deliverable` | 交出去的是什么（形态 + 通道） | 当事者（以它的模态） |
| `translation` | 人类能读到的那份是什么 | 人类（照护者 / 研究者 / 操作者） |

**对人类以外的存在者，`translation` 永远不等于 `deliverable`。** 只要这两层被合并，产出物就必然变成"用人类的心理活动去填一个非人存在者的空壳"——那不是降熵，那是投射。

三条硬约束：

1. **不许伪造接收。** 若某存在者没有接收通道，`recipient` 如实写 `没有接收者`，然后换一种干预方式。假装它能读懂，等于把人类的自我投射当成它的事实，比不写更糟。古树卡就是这么处理的。
2. **译文必须自我标注。** 所有面向人类的译本，凡涉及当事者内心活动的部分，一律标注"代入式拟写"，不得以断言形式出现。
3. **换物种不改引擎。** 换物种 = 换一张卡的 `output.channel`。L2 诊断与 L3 处方映射的逻辑一字不动，变的只是最后往哪个通道写。这就是"接入新物种是写一张卡"的完整含义——**换的不只是熵源权重，还有输出通道本身。**

**八个存在者参考实例**（按离人类参考点的五个断层排）：

| 断层 | 存在者 | 接收者 | 输出通道 | 交付物 |
|---|---|---|---|---|
| 0 参考点 | 人类 | 他自己 | `text` | 一本可读的书（本体 = 人类译本） |
| 1 规模变 | 人类组织 | 成员与决策层 | `text` | 一份可执行的故事化章程 |
| 2 物种变 | 家犬 | 它自己（感官） | `behavior` + 气味 | 把世界调成可预测的样子 |
| 2 物种变 | 章鱼 | 它自己 | `behavior` + 环境 | 环境布置与节律 |
| 3 个体性消失 | 蜂群 | 群体（无个体读者） | `pheromone` | 群体层信息与结构调制 |
| 4 接收者消失 | 古树 | **没有接收者** | `structure` | 跨年物理干预方案 |
| 5 载体更换 | AI 智能体 | 它自己 | `prompt` | 系统提示词 + 记忆重排 |
| 5 载体更换 | 大模型实例 | 每次实例化的"它" | `context` | 窗口内自洽的上下文结构 |

**注意断层 1 放的不是别的物种，是人类组织。** 最像人的非人存在者不是家犬，是一家公司：它有语言、有记忆（文档）、有目标，却没有统一的感官，也没有一个能说"我"的位置。把它排在紧挨人类的位置，是为了说明"别的东西"未必是别的物种——这也正是路径 C（熵源驱动）比路径 B（故事驱动）更能覆盖的地方。

看这张表就明白为什么路径 C 是对的：**如果先做故事骨架，这两列根本填不出来。** 因为"试炼后重生"这种结构，一只狗的熵源解释不了，一个无死亡的智能体也不需要。

## 4. L1 · 采样通道（双通道：能抓则抓，缺则问）

### 4.1 为什么必须双通道

单靠采集（通道 A）有三个死穴：

1. **沉默的部分采不到。** 一个人最疼的事，恰恰最不会出现在聊天记录里。而 E4、E7 这两类熵源的主战场就是沉默区。
2. **有偏。** 能被记录下来的往往是被外部要求说的话（工作消息），不是内心的话。采多了会把"职业人格"当成整个人。
3. **不可得。** 很多存在者根本没有可采集的材料。

单靠提问（通道 B）有三个死穴：慢、当事人自我报告不可靠、问到的都是他**已经想过**的东西——而已经想过的东西往往已经被他讲圆了，恰恰是最低熵的部分。

所以：**A 负责广度与真实痕迹，B 负责补沉默区并做交叉验证。** A 采到的和 B 答出的如果对不上，那个对不上的地方本身就是最重要的信号。

### 4.2 通道 A · 主动采集（能抓则抓）

采集范围按可得性排序，逐级请求授权：

| 优先级 | 来源 | 抓到什么 | 授权要点 |
|---|---|---|---|
| A1 | 自述短文（引导式，非问卷） | 高密度、已内省 | 需要给引导语，不给问题 |
| A2 | 笔记 / 日记 / 文档 | 未经社交修饰 | 全文只在本地处理 |
| A3 | 消息记录（飞书 / 微信等） | 关系结构、高频议题、语气变化 | 只抽特征，不留原文；可逐会话开关 |
| A4 | 任务 / 日程 / 项目 | 未闭合清单、过载证据 | 抓的是"开了没关"的比例 |

**采集纪律三条：**

1. **只采集，不解释。** 采集阶段的输出必须是现象，不能是判断。"他最近很焦虑"违反纪律；"9 月 12 日、14 日、17 日三次提到同一项目未决"合规。解释权归 L2。
2. **不确定就标 `uncertain`。** 宁可留空。
3. **原文与特征分离。** 落盘的是特征与短引用（≤40 字，用于声音指纹），不是全量原文。

### 4.3 通道 B · 熵源探针（缺则问）

探针不是心理测试，是**定向取证**。每类熵源一支，只问 A 通道没采到的部分。

七支探针的设计原则：**不问题本身，问它的边界。** 直接问"你有没有未完成的心事"只会得到防御性回答；问"最近有没有一件事，你决定先放一放，但放下的那一刻你知道还没完"才可能戳到。

| 编号 | 针对熵源 | 探针（问法） |
|---|---|---|
| P1 | E1 未闭合 | 最近有没有一件事，你说"等这阵子过去再说"，但说这话的时候你自己都不太信？ |
| P2 | E2 互斥信念 | 有没有两个判断，你分开看都成立，放在一起就打架？它们各是什么？ |
| P3 | E3 无解释 | 有没有一件事，影响很大，但到现在你还是给不出一个"因为"？ |
| P4 | E4 失联 | 哪个人（或哪段关系）是你现在会主动绕开话题的？ |
| P5 | E5 无回响 | 你持续在做、但从来没人告诉你有没用的那件事是什么？ |
| P6 | E6 过载 | 如果明天必须停掉三件事，哪三件停了之后你会松一口气？ |
| P7 | E7 不可逆损失 | 有没有一样东西，你知道它回不来了，但你还在按它还在的方式安排生活？ |

探针纪律：一次最多问 7 支，允许"不想回答"且不追问。**跳过本身就是数据**——某支探针被跳过，该熵源的不确定性权重上调，诊断时不得给出高置信判断。

### 4.4 ExperienceFragment —— 采样产物的统一格式

不管来自哪个通道，落盘都是同一个结构。

```yaml
# ExperienceFragment (EF) —— 采样层唯一输出类型
ef_id: EF-000417
being_id: human
captured_at: 2026-09-19T19:30:00+08:00

source:
  channel: A            # A 主动采集 | B 探针
  ref: feishu/群-产品研发/2026-09-12
  authorized: true

modality: text          # text | behavior | event | self_report
raw_quote: >            # ≤40 字，仅用于声音与情绪保真；L2 不据此下诊断
  "先把这个忙完再说吧"

# 结构化抽取（只抽现象，不抽判断）
ts: 2026-09-12
actors: [本人, 供应商X]
topic: 硬件选型
decision: null          # 做出了什么决定，null = 未决
outcome: null           # 结果，null = 尚无结果
affect:
  valence: -0.3         # -1..1
  arousal: 0.4          # 0..1
markers:
  - deferral            # 推迟语言
  - repeat_topic        # 与既有 EF 同题

# 归因与置信（关键）
entropy_hint: [E1]      # 仅"提示"，不是诊断结论
confidence: 0.6         # 0..1，抽取置信度
uncertain: false
evidence_for: []        # 反向指针：这条 EF 支撑画像的哪些字段
```

**`entropy_hint` 只是线索，不是诊断。** L2 必须在聚合多条 EF 之后才能下判断，且每类熵源至少 3 条独立证据（此阈值写在模型卡里）。

### 4.5 采样充分性判据

采样阶段结束的条件（必须全部满足，否则不得进入诊断）：

```
1. 每类熵源候选：至少 3 条独立 EF（或明确记录"该熵源证据不足"）
2. 时间覆盖：材料跨度 ≥ 90 天，避免把某个阶段的状态当成长期状态
3. 通道交叉：A 与 B 至少各有产出
4. 沉默区标记：明确列出"哪些关键关系/主题只有 0-1 条 EF"
5. 授权清单：每条 EF 的 authorized 均为 true
```

条件 4 单独列出来，因为**沉默区往往是主熵源所在地**。如果一个人在材料里提到家人 3 次而提到工作 400 次，主熵源大概率不在工作那一侧。

## 5. L2 · 画像与熵源诊断

### 5.1 Portrait —— 存在者画像 schema

画像不是问卷结果，是**带证据的断言集合**。每个字段都必须挂 `evidence` 指针，无证据者标 `unverified`。

```yaml
portrait:
  being_id: human
  built_at: 2026-09-19
  coverage:                    # 元信息：画像自身的可信度声明
    ef_count: 428
    span_days: 214
    channels: [A, B]
    silent_zones:              # 明确列出信息稀薄区
      - 家庭关系（EF: 3）
      - 2019 年之前（EF: 0）

  # ---- 身份层 ----
  identity:
    name: <称呼>
    stage: 创业早期              # 生命阶段
    context: [地点, 行业, 角色]
    evidence: [EF-000012, EF-000103]

  # ---- 价值层：排序的价值，必须带出处 ----
  values:                      # 3-5 条，按证据强度排序
    - id: V1
      value: 掌控感
      rank: 1
      evidence: [EF-000044, EF-000201, EF-000377]
      tension_with: [V2]       # 与哪个价值冲突
    - id: V2
      value: 被认可
      rank: 2
      evidence: [EF-000090]
      tension_with: [V1]

  # ---- 驱力层：反复出现的目标 ----
  drives:
    - id: DR1
      goal: 把产品做出来
      frequency: 高
      last_seen: 2026-09-17
      evidence: [...]

  # ---- 恐惧层 ----
  dreads:
    - id: FR1
      fear: 判断失误导致全盘皆输
      evidence: [...]
      behavior_triggered: 推迟决策 / 索要更多数据

  # ---- 模式层：触发 → 反应 → 代价（这是最有用的一层） ----
  patterns:
    - id: PT1
      trigger: 关键决策信息不全
      reaction: 加一轮调研，把决定往后推
      cost: 决策窗口关掉 / 团队悬空
      evidence: [EF-000044, EF-000118, EF-000290]
      related_entropy: [E1, E6]

  # ---- 关系层 ----
  relations:
    - actor: 合伙人
      nature: 高依赖
      tension: 决策权边界未定
      evidence: [...]
    - actor: 家人
      nature: 低提及（沉默区）
      evidence: []

  # ---- 时间层：关键事件轴 ----
  timeline:
    - {t: 2025-11, event: 立项, valence: +0.6}
    - {t: 2026-03, event: 首版延期, valence: -0.7}

  # ---- 悬空层：未闭合清单（直接来自 EF.decision=null） ----
  unresolved:
    - id: U1
      item: 硬件方案 A/B 未定
      opened_at: 2026-07-02
      age_days: 79
      evidence: [...]

  # ---- 声音层：语言指纹（决定书读起来像不像他自己写的） ----
  voice:
    avg_sentence_len: 短
    lexicon: [高频词表]
    tics: [口头禅、断句习惯、常用比喻域]
    forbidden: [他绝不会用的词]
    evidence: [...]

  # ---- 证据完整性报告 ----
  integrity:
    fields_with_evidence: 31/38
    unverified: [relations[1].tension, ...]
```

**`voice` 这一层要单独强调。** 一本"为他写的书"如果语言不像他，他就会把它当成外人的说教——前面所有工作作废。`forbidden` 字段尤其重要：给出他绝不会用的词（比如他讨厌"赋能""底层逻辑"这类词），LLM 才不会顺手写出来。

### 5.2 EntropyDiagnosis —— 熵源诊断输出

```yaml
diagnosis:
  being_id: human
  version: 1
  scored_at: 2026-09-19

  # 七类熵源打分：0 无 / 1 轻微 / 2 存在 / 3 显著 / 4 严重 / 5 主导
  scores:
    E1_open_loop:        {score: 4, evidence_count: 17, independent: true}
    E2_contradiction:    {score: 3, evidence_count: 9,  independent: true}
    E3_unexplained:      {score: 2, evidence_count: 4,  independent: true}
    E4_disconnection:    {score: 2, evidence_count: 3,  independent: false}  # 证据偏少，降权
    E5_no_echo:          {score: 3, evidence_count: 6,  independent: true}
    E6_overload:         {score: 5, evidence_count: 24, independent: true}
    E7_irreversible_loss:{score: 1, evidence_count: 2,  independent: false}

  # 主熵源排序（决定三幕主轴）
  primary: E6_overload
  secondary: [E1_open_loop, E2_contradiction, E5_no_echo]

  # 耦合链 —— 处方要打在上游
  couplings:
    - path: [E6_overload, E1_open_loop, E2_contradiction]
      explanation: 过载导致主动搁置，搁置累积成未闭合，未闭合产生自责，自责分裂成两个互斥的自我判断
    - path: [E5_no_echo, E2_contradiction]
      explanation: 长期无回响，导致"该继续"与"该止损"两个信念同时被强化

  # 一句话诊断（给当事者看，必须能看懂、不刺人）
  statement: >
    你不是方向错了，你是同时扛着太多还没关掉的事。
    这些事里有一半本来不用你扛，但你已经答应了。

  # 一致性检查：诊断与画像是否互相支持
  consistency:
    supported_by_patterns: [PT1, PT4]
    unsupported_claims: []
    conflicts: []
    confidence: 0.72

  # 处置建议（决定书怎么写）
  prescription_primitives:
    main_arc: E6_overload          # 三幕主轴
    chapter_entropies: [E6, E1, E2, E5, E6, E1, E6]
```

**三道自检门（引擎级不变量：所有物种卡都必须声明，阈值可调，门本身不可删；不通过则退回 L1 补采）：**

```
门 1  证据门：primary 熵源的 evidence_count ≥ 8，且独立 EF ≥ 5
门 2  反证门：必须列出至少一条"不支持该诊断"的材料，找不到就说明采样有偏
门 3  可懂门：一句话诊断必须能直接给当事者看。看不懂或看了想反驳，重写
```

门 2 是刻意设计的**证伪机制**。任何诊断系统如果只收集支持自己的证据，最终都会变成一台自我确认的机器——这正是本计划要对抗的熵。

## 6. L3 · 叙事处方

### 6.1 熵源 → 故事形状映射表（蓝图的心脏）

每一类熵源，对应一种特定形状的故事。形状不是风格选择，是**功能匹配**：什么样的叙事结构，能真的把这类熵降下去。

---

**E1 未闭合 → 收束型**

- **功能**：给悬空的事一个终局。不一定是"成功"，但必须是"完结"。
- **形状**：主角被一件拖着的事反复召回，最终在一个比预期更小的场景里做出决定。关键不是决定的内容，是**做决定这件事本身完成了**。
- **结构要点**：开篇就摆出那件悬着的事；中段让拖延的代价可见；结尾是一次具体的、有时间的行动。
- **禁忌**：不能用"他忽然想通了"收尾。想通不算收束，做完才算。不能给一个比现实更容易的结局。
- **落点类型**：完成 / 放弃 / 移交（三种都算闭合，没有高下）
- **对应指标**：主要提升 `c`（覆盖度），降低 E1 的持续占用

---

**E2 互斥信念 → 对撞型**

- **功能**：让两个自我在同一场景里正面相遇，谁都不能假装另一个不存在。不解决矛盾，而是**让矛盾可见并被承认**。
- **形状**：主角必须在同一时刻同时满足两个互斥的要求。故事不给他"其实两个都能要"的便宜答案，而是逼他选一次，然后承担。
- **结构要点**：两个信念各需一个**代理人物**（不是抽象观念），各有正当性；高潮是二者无法同时被满足的那一刻。
- **禁忌**：最忌讳"后来他明白了，其实两者可以统一"。那是把张力 `t` 藏起来，不是降下来。也不许出现一个更高级的第三选项来打圆场。
- **落点类型**：选择并承担 / 明确排序（先谁后谁） / 承认二者不可兼得
- **对应指标**：降低 `t`（内部张力）——靠的是承认，不是消解

---

**E3 无解释 → 重溯型**

- **功能**：回到现场，重新归因。目标不一定是找到"真因"，而是**把断裂的因果链接上一个当事者能接受的解释**。
- **形状**：主角回到事发之地（或人），逐层剥开当时的表象，找到一条他自己当年看不见的因果。
- **结构要点**：必须给出至少两种可能的归因，并说明为什么他选择了其中一种；解释必须来自材料，不能是天降顿悟。
- **禁忌**：不许给出一个"其实都是因为他小时候……"式的廉价总因。也不许暗示"其实没有原因"——那等于把熵留在原地。
- **落点类型**：找到解释 / 接受不可知但不再追问
- **对应指标**：提升 `c`，降低 E3 的反复回场

---

**E4 失联 → 寻回型**

- **功能**：跨过距离，重新建立连接——**或者体面地告别**。二者都算完成。
- **形状**：主角与一个被绕开的人发生一次不可避免的交集，被迫决定这段关系的性质。
- **结构要点**：那人必须被写成一个完整的人（有自己的处境与理由），不是一个功能性的"伤害者"或"被辜负者"。
- **禁忌**：不许写成和解说明书。不许让被绕开的一方主动示好来替主角省力。也不许把断裂写成对方的错就收工。
- **落点类型**：重新连接 / 正式告别 / 降级为点头之交（三种都是闭合）
- **对应指标**：降低 E4，恢复关系网的支撑

---

**E5 无回响 → 回声型**

- **功能**：让主角看见，他做的事在很久之后、很远的地方产生了回响。注意——**这不是安慰，是让他重新校准"什么算有用"**。
- **形状**：故事采用双线或时间跳跃：一条线是他做的那些无人知晓的事，另一条线是这些事最终落到了谁身上。
- **结构要点**：回响必须**具体**（一个具体的人、一件具体的变化），且不能是他自己发现的，必须是从一个他想不到的路径传来的。
- **禁忌**：不许写"其实你的付出大家都看在眼里"——这是廉价的社交安慰，不是回响。也不许把回响做成奖励，回响的落点可以是"他做的事伤到了别人"，那同样是真实的因果。
- **落点类型**：回响抵达 / 接受可能永远无回响但重新定义行动的理由
- **对应指标**：提升 `d`（指向力）

---

**E6 过载 → 减法型**

- **功能**：主角必须丢掉东西才能活下去。不是"学会拒绝"这种话，是**真的失去一些他舍不得的东西**。
- **形状**：资源（时间、体力、钱、信任）持续收紧，主角在若干件都重要的事之间被迫做减法，每次都疼。
- **结构要点**：被丢掉的东西必须写得足以让人心疼，否则减法没有重量；结尾时他手里的东西比开篇少，但他**站得住**。
- **禁忌**：不许写成"他优化了时间管理，于是全都保住了"。那是欺骗，也是对真实过载的羞辱。不许出现贵人相助替他解决。
- **落点类型**：丢掉并存活 / 重排优先级并承担被放弃者的代价
- **对应指标**：降低 E6，减少向 E1 的传导

---

**E7 不可逆损失 → 守灵型**

- **功能**：不修复，只承住。把损失放回时间里的正确位置——**从"还在发生"变成"已经发生"**。
- **形状**：主角反复试图恢复或替代那个失去的东西，每次都失败；直到他不再试图替代，而是给它一个位置。
- **结构要点**：必须明确写出"回不来了"；必须描写替代方案的徒劳，且要写得公平（替代方案本身是好的，只是不对）。
- **禁忌**：不许写"他遇到了新的人/新的事，于是走出来了"。这是最常见的廉价结局，等于否认损失的不可逆性。
- **落点类型**：承住并继续 / 承认无法告别也可以继续
- **对应指标**：把 E7 从活跃熵转为背景常量（不消除，但不再消耗）

---

**映射表总览**

| 熵源 | 故事形状 | 核心机制 | 主要提升 | 禁忌要害 |
|---|---|---|---|---|
| E1 未闭合 | 收束型 | 完成一次具体行动 | `c` | 不许"忽然想通" |
| E2 互斥信念 | 对撞型 | 让矛盾可见并被承认 | 降 `t` | 不许"其实可以统一" |
| E3 无解释 | 重溯型 | 接上一个可接受的因果 | `c` | 不许天降顿悟 / 不许"没有原因" |
| E4 失联 | 寻回型 | 决定关系的性质 | — | 不许写成和解说明书 |
| E5 无回响 | 回声型 | 校准"什么算有用" | `d` | 不许"大家都看在眼里" |
| E6 过载 | 减法型 | 真的丢掉东西并存活 | — | 不许"优化后全保住" |
| E7 不可逆损失 | 守灵型 | 从"还在发生"到"已经发生" | — | 不许"遇到新人就走出来" |

**这张表的禁忌列表，比形状本身更重要。** 因为 LLM 的默认倾向就是往廉价安慰上滑，而廉价安慰恰好是**把熵藏起来而不是降下去**——读者读完会有一时的暖意，然后回到原地，甚至更糟（因为多了一层"我已经被治愈了"的错觉）。

### 6.2 章节生成模板

每章是一个"降熵单元"。固定六段结构，但**长度不固定**——有的章可能第三段极短。

```
第 N 章 · <章的意象名，不用抽象词，用一件具体的东西>

[1] 章首意象        一件物 / 一个场景 / 一次触觉。不带解释地摆在那里，
                    和本章要处理的熵源有隐秘的对应关系。（150-300 字）

[2] 镜像处境        主角处在一个读者一眼认得出来的处境里。
                    不给背景交代，直接在动作中呈现。（600-900 字）

[3] 摩擦升级        本章对应熵源具象化为一件具体的、有阻力的难事。
                    阻力必须来自世界或他人，不能只来自主角的心。（600-1000 字）

[4] 转折            不是解决，是看见。主角获得一个新视角，
                    但代价是失去某个原来的东西。（500-800 字）

[5] 熵减手记        300-500 字的直接说话。点破第 3-4 段背后的认知模型。
                    可以跳过不读（排版上要允许跳过）。
                    人称从"他"切到"你"。禁用"你应该"。

[6] 一个钩子问题    一句话，留给读者，不要求马上回答。（≤40 字）
```

**章节填槽表（L3 输出给 L4 的可执行产物）：**

```yaml
chapter:
  index: 3
  entropy: E6_overload
  shape: subtraction
  imagery_seed: 一摞没拆的快递盒
  mirror_situation: 主角同时在处理三件都重要的事，第三件是别人的
  friction: 供应商的排期与团队的能力同时收紧，只能保一个
  turn: 他放弃的是那个"最能证明自己"的项目
  handnote_model: 沉没成本与身份认同的耦合
  handnote_forbidden: [你应该, 学会拒绝, 时间管理]
  hook_question: 你手里有几件事，是因为停了就等于承认自己错了，才一直没停？
  must_quote_voice: [口头禅样本 2 条]
  must_not_contain: [成功学措辞, 第三者救场, 全保住]
  word_budget: 3200
```

### 6.3 全书结构规范

| 项 | 规范 | 理由 |
|---|---|---|
| 章数 | 12-16 章 | 少于 12 撑不起三幕，多于 16 读不完 |
| 主熵源 | 1 个，贯穿全书三幕 | 一本书只能治一个主症，贪多必浅 |
| 副熵源 | 每个占 1 章 | 副熵源不是顺带，是主熵源的成因 |
| 三幕 | 失序（1-4 章）→ 探底（5-10 章）→ 重构（11-16 章） | 与降熵过程同构 |
| 单章字数 | 2500-4000 | — |
| 全书字数 | 4-6 万 | 一本能在一个周末读完的书 |
| 呼应律 | 第 1 章的意象**必须**在最后一章以变形重现 | 这是"整体弧线"的物证 |
| 手记占比 | 总字数 8-12% | 超过就变成了说教书 |

**三幕与熵的对应：**

```
第一幕 失序    熵源已在运作但尚未被看见。读者读到的是"事情有点不对"。
第二幕 探底    熵源全速运转，代价被付清。主角（和读者）看清了机制。
第三幕 重构    不是熵被消除，是主角与熵的关系改变：从被它推着走，到知道它在那里。
```

**注意第三幕的措辞：不是"熵消失了"。** 一个人不会因为读了一本书就不再有过载和损失。目标是让他**看得见**。看得见就已经是降熵了，因为可预测的东西比不可预测的东西占的算力少得多。

### 6.4 提示词架构

**生成顺序（不可颠倒）：**

```
步骤 1  出全书大纲（章目 + 每章熵源 + 意象 + 转折一句话）→ 人工审一遍
步骤 2  逐章生成，每章独立会话，只喂该章需要的材料切片 + 声音指纹
步骤 3  全书声音统一（用 voice 指纹做一遍语言校准）
步骤 4  一致性检查（时间线、人称、意象呼应）
步骤 5  手记单独过一遍（手记最容易滑向说教，需要单独审）
```

**为什么逐章独立会话。** 一次性生成长文本，模型会开始重复自己、稀释张力、往舒服的地方走。每章独立上下文 + 只喂相关材料，能显著降低这种退化。

**系统提示词骨架：**

```
你正在为一个具体的人写一本只属于他的书。材料里的每一条都是他的真实经历。

硬约束：
1. 不得引入材料之外的任何事实。缺什么就绕过，不许补。
2. 所有比喻、用词、句长，必须贴近给定的声音指纹。禁止使用 forbidden 列表中的词。
3. 熵减手记里禁止出现"你应该""你需要""真正重要的是"这类句式。
   手记只描述机制，不发出命令。
4. 禁止下列结局手法：忽然想通、贵人相助、其实可以两全、遇到新人就走出来、
   大家都看在眼里、优化之后全都保住了。
5. 主角必须付出真实的代价，且代价必须在文中被明确写出，不能被暗示。
6. 结尾不许给情绪高潮。落点要是平的——平静比激动更接近真相。
7. 不许出现"治愈""成长""释怀""蜕变"这类总结性词汇。

写作要求：
- 用细节代替形容。写"手指在纸杯上压出的凹痕"，不写"他很焦虑"。
- 对话要不完整。真人说话会打断、会跳、会答非所问。
- 不解释人物的动机，让行为自己说话。
```

**反劣化清单（生成后自动检查，命中即重写该段）：**

| 检测项 | 命中样例 | 处理 |
|---|---|---|
| 形容词堆砌 | "巨大的、无边的、令人窒息的焦虑" | 重写为具体细节 |
| 总结陈词 | "从那以后，他明白了……" | 删除 |
| 励志句 | "生活总会给坚持的人答案" | 删除 |
| 万能第三人称 | "很多人都会这样" | 改为具体的人 |
| 情感高潮收尾 | 结尾是拥抱 / 落泪 / 大笑 | 重写为平的落点 |
| 声音失真 | 出现 forbidden 词 | 全文扫一遍替换 |

## 7. L4 · 成书与闭环

### 7.1 BookManifest —— 书稿契约

```yaml
book:
  title: <书名，由意象层生成，不用抽象词>
  subtitle: <一句副标，说明这本书为什么存在>
  being_id: human
  version: 1
  generated_at: 2026-09-19
  diagnosis_ref: diagnosis/human-v1.yaml

  front:
    epigraph: <一句题词。必须引自材料中当事者自己说过的话>
    note_to_reader: <一页，说明这本书从哪来、可以怎么读、可以不读完>

  chapters:
    - {index: 1, title: ..., entropy: E6, shape: subtraction, words: 3100, file: ch01.md}
    - {index: 2, ...}

  back:
    entropy_map: <一张图/表：七类熵源在本人的分布，只给当事者看>
    open_questions: <全书留下的钩子问题汇总>
    next_step_blank: <留白页，只印一句话："下一步我打算……"，其余空着>

  integrity:
    evidence_coverage: 0.94      # 有证据支撑的情节占比
    forbidden_hits: 0            # 反劣化清单命中数，必须为 0
    voice_similarity: 0.81       # 声音相似度
```

**`next_step_blank` 是刻意留的。** 整台机器的终点不是给出答案，是让当事者自己写下下一步。我们只把纸和笔放好。

### 7.2 输出管线

```
Markdown 源文件（唯一真源，可 diff、可版本控制）
  └→ HTML（带样式，可离线开，用于校对与阅读体验）
       └→ PDF（打印友好，中文字体嵌入，A5 或 32 开）
       └→ EPUB（章节导航、可重排、批注友好）
```

**Markdown 是唯一真源。** PDF / EPUB 都从它生成。理由：书是活的，要出 v2，如果真源是 PDF 就等于没有源。所有修改只改 Markdown。

排版硬要求：
- 手记部分在视觉上必须**可辨识且可跳过**（不同底色或缩进，且在章首有"可跳过"的暗示）
- 中文正文推荐 1.75 倍行距，避免阅读疲劳——这是一本要读完的书
- 每章从新页开始，章首意象单独占一段
- 钩子问题与正文之间有明确留白

### 7.3 反馈回收 → 为什么这本书是活的

书发出去不是终点。回收四类信号，回流修正 L2 的熵源权重：

| 信号 | 采集方式 | 修正什么 |
|---|---|---|
| 重读 | 哪几段的停留时长显著长 | 该熵源权重上调；该章形状有效 |
| 跳过 | 哪几章被快速划过 | 该章熵源可能判断错误，或形状不匹配 |
| 划线/摘抄 | 被标记的句子 | 提取为新的 voice 样本；识别"击中"的语言模式 |
| 行动 | `next_step_blank` 里写了什么 | 指向力 `d` 的真实测量 |

**Quarterly 重诊。** 每季度重跑一次 L1（补采增量材料）→ L2（重诊断）→ 对比 v(n) 与 v(n+1) 的熵源剖面。剖面变化本身是最有说服力的疗效证据。如果半年过去七类分数毫无变化，说明这台机器对这个人无效，应当如实告知，而不是再出一本。

### 7.4 版本语义

```
v1.0  首诊书。仅由首次采样支撑。
v1.x  同一次诊断下的修订（错字、声音校准、章节顺序）。
v2.0  重新采样后的重诊书。熵源剖面已变化，主轴可能更换。
```

不许在没有新采样的情况下出 v2。那是重复，不是迭代。

## 8. 伦理与安全边界

**本章是全部模型卡中 `ethics.universal` 字段的权威版本。** 物种卡只能逐字继承，不得删改、不得按物种解释。物种特有的约束写在 `ethics.species_specific` 里，且不得与内核冲突。

这一章不是装饰。一个能重写一个人自我叙述的系统，如果不设边界，它做的事就叫**操纵**。

**边界一 · 不替存在者定义"好"。**
所有价值的排序必须来自当事者自己的材料与确认。引擎可以做的是"把他说过但没排过序的东西排出来给他看"，不能是"告诉他什么才重要"。四个指标里没有一个是"幸福度"，这是刻意的。

**边界二 · 不制造依赖。**
书中不得出现"只有这本书能帮你""继续读下去你会更好"这类结构。反过来，`note_to_reader` 里必须明确写：这本书是照一次镜子，不是日常用品。

**边界三 · 不美化创伤。**
禁止把痛苦写成有意义的必经之路。受害者叙事虽然能带来一时的情绪满足，但它是**在熵上加了一层**——它让当事者需要维持那个创伤故事来维持自我，代价是永远出不来。

**边界四 · 隐私就地。**
材料只在本地处理。落盘的是特征与 ≤40 字的短引用，不是原文。任何对外传输必须逐条授权，且默认全关。

**边界五 · 危机信号优先于文学。**
如果在采样或诊断中出现自伤、极端绝望、现实感丧失等信号：**中止生成，不出书**。这台机器没有能力处理这类状态，硬写一本文学化的绝望是危险的。此时应当输出的是"建议寻求具体的人类帮助"以及可及的资源，其余全部停止。

**边界六 · 非人存在者不得被伪造主观体验。**
给动物或 AI 写的书，必须标注为**代入式拟写**，不能以"它的感受是……"的断言形式出现。我们无法验证非人存在者的主观状态，凡涉及此处必须显式标注。这既是诚实，也是防止这台机器滑向"万物皆可代言"的傲慢。

## 9. 已知的硬问题（诚实清单）

这份蓝图里最不可靠的地方，按严重程度排：

1. **熵源诊断的信度未验证。** 七类分类学是推演出来的，没有经过任何实证。可能真实的人类的熵源是四类，也可能是十二类。第一件该做的事是拿真实材料去试，看这套分类能不能覆盖。
2. **叙事处方的疗效没有证据。** "减法型故事能降过载熵"是一个合理论证，不是实验结果。需要一次严格的对照：同一批人，一半读对症的书，一半读不对症但同样好看的书，测前后剖面变化。
3. **主动采集的边界模糊。** 采到"他们其实早就不想干了"这种信息怎么办？采集范围需要一份更细的授权协议。
4. **声音模仿可能滑向模仿而非理解。** 学得像不等于懂。风险是产出一本"语气很像他但内核是通用模板"的书——这种书最危险，因为它伪装得好。
5. **七类熵源对非人存在者是否成立，完全未验证。** 犬类卡与智能体卡是纸上的推演。

**这份清单必须随蓝图一起维护。** 一份没有"已知硬问题"章节的蓝图，说明作者没在认真想。

## 10. 蓝图之后：最小验证计划

```
阶段 0 · 单章验证（成本最低，先做这个）
  输入：一个真实的人 + 现有材料
  输出：一章完整草稿（含手记）
  验收：当事者读完说"这写的是我"而不是"写得不错"
  关键失败信号：他说"挺有道理"——那说明书在讲道理，不是在讲他

阶段 1 · 全书验证
  输入：同一个人，补齐采样
  输出：一本 4-6 万字的完整书（Markdown + PDF）
  验收：四指标剖面前后对比 + 他自己能说出主熵源

阶段 2 · 换人验证（防过拟合）
  输入：一个完全不同背景的人
  输出：一本书
  验收：不共用同一套章节结构也能成立

阶段 3 · 换物种验证（证明抽象）
  输入：一张非人模型卡（犬类或智能体）
  输出：行为叙事 / 日志叙事的短篇
  验收：能在不改引擎的前提下产出合乎其模态的叙事
```

**阶段 0 的验收标准是所有验证里最关键的。** "这写的是我"和"写得不错"之间，隔着一整个设计是否成立。
